# Adversarial security assessment

Assessment date: 2026-09-14. The review treated source names, paths, redirects, downloads, archives, document contents and extracted text as untrusted data. It covered the application service, source adapters, local and host runtimes, review panel, persistence, conversion, verification, packaging and bootstrap.

## Findings and disposition

| Area | Evidence and adversarial result | Classification | Disposition |
| --- | --- | --- | --- |
| DNS rebinding | `runtimes/local.py` preflight resolution was followed by a separate urllib resolution. A controlled resolver changed a public answer to loopback and the local test server was reached. | **CONFIRMED VULNERABILITY** | The HTTP provider now validates and pins the addresses used by its socket connection, rechecks on redirects and disables ambient proxies. Regression: `test_dns_rebinding_is_rejected_before_connection`. |
| Secret persistence | `domain.py` scrubbed selected query keys but left `api_key`, `access_token`, `client_secret` text and opaque secret-like path components in reports/provenance. | **CONFIRMED VULNERABILITY** | Common credential forms and secret-like path components are scrubbed; stable registrations containing those path components are rejected. Text exports remain conservative and block recognised secrets. |
| Derived Markdown links | HTML conversion emitted `javascript:` and `data:` destinations supplied by source content. | **CONFIRMED VULNERABILITY** | Markdown conversion emits only HTTP(S) links and neutralises dangerous schemes. Regression: `test_derived_markdown_neutralizes_executable_schemes`. |
| Malformed URLs | An invalid port in one page link raised `ValueError`, pausing the whole discovery run and hiding valid neighbouring links. | **CONFIRMED VULNERABILITY** | Invalid links are isolated as excluded gaps. Regression: `test_malformed_link_does_not_abort_other_navigation`. |
| Local data permissions | Fresh projects created 0755 directories and a 0644 SQLite database under the default umask. | **CONFIRMED VULNERABILITY** | Project, staging, report and export directories are 0700; metadata and generated reports are 0600; SQLite uses a private rollback journal. Regression: `test_store_and_reports_are_private`. |
| Hardlink aliases | A hardlink in a source folder pointed at a project-private file and was captured by pathname validation. | **CONFIRMED VULNERABILITY** | Regular files with link count greater than one are excluded during discovery and capture. Regression: `test_hardlinked_project_file_is_not_ingested`. |
| Parent/symlink traversal | Existing tests excluded normal symlinks and project/output recursion. Pathname capture used final `O_NOFOLLOW`, but parent replacement remained theoretically raceable. | **DEFENCE-IN-DEPTH IMPROVEMENT** | Supported POSIX paths now use component-by-component descriptor-relative stat/open with no-follow flags. Other platforms retain pathname checks. |
| Absolute and encoded traversal | `Scope.permits` rejects paths outside filesystem roots and encoded `..` web segments. Existing tests cover both. | **ALREADY MITIGATED** | Retained and covered by the existing traversal tests. |
| Archive Zip-Slip | Verification reads archive metadata and required members only; CDC never extracts archive member paths. Expansion is bounded by member count and total uncompressed size. | **NOT APPLICABLE** | Regression confirms a malicious ODT member is never extracted: `test_zip_slip_member_is_never_extracted`. |
| Prompt injection | Source text is stored as observations/data. Tool schemas expose no approval operation, and approval is performed only by the local user review boundary. Existing tests cover this boundary. | **ALREADY MITIGATED** | Untrusted text cannot grant scope, approval, command execution or new tool definitions. A compromised host/model remains outside this application guarantee. |
| SSRF/private addresses | Loopback, private, link-local, mapped IPv4/IPv6 and common integer/hex forms were rejected in probes. Legacy numeric spellings were platform-dependent. | **DEFENCE-IN-DEPTH IMPROVEMENT** | Ambiguous numeric IPv4 spellings are rejected before resolution; every resolved address is checked. Regression: `test_ambiguous_numeric_ipv4_spellings_are_rejected`. |
| Ambient proxies | urllib's default opener could honor process proxy variables and move an otherwise scoped request through an intermediary. | **DEFENCE-IN-DEPTH IMPROVEMENT** | The provider uses an empty `ProxyHandler`; regression: `test_ambient_proxy_settings_do_not_redirect_http`. |
| Browser network and buffering | Optional browser providers can execute page JavaScript, open additional pages and buffer downloads before limits apply. | **REQUIRES MANUAL/PLATFORM TESTING** | Provider limitations remain disclosed. Strict transfer ceilings require bounded HTTP or a separately constrained browser runtime. |
| Parser/subprocess exhaustion | Conversion has a timeout, output-size limit and archive expansion checks, but is not a complete OS sandbox or memory quota. | **DEFENCE-IN-DEPTH IMPROVEMENT** | Output manifests are validated as basename-only paths before promotion. Full OS-level sandboxing and memory limits were deferred to avoid breaking supported converters. |
| Review boundary | Loopback Host/Origin/nonce checks, one-use forms, payload hashes and no model approval tool are covered by existing tests. A same-account process can still operate the panel. | **ALREADY MITIGATED** | Same-account compromise remains a documented residual risk. |
| Supply chain/bootstrap | Bootstrap runs checked-in code and installs declared dependencies; package actions are pinned in CI. | **REQUIRES MANUAL/PLATFORM TESTING** | Repository trust, GitHub branch protections, secret scanning and account security remain platform controls. |

## Existing defenses verified

The review also confirmed these controls and their existing evidence: `Scope.permits` and `Application.register_source` require explicit roots and reject absolute/encoded traversal (`tests/test_application.py`, `tests/test_web.py`, `tests/test_derivation_and_protocol.py`); filesystem discovery excludes symlinks, special files, project/output recursion and uses file identity/change checks (`tests/test_application.py`); HTTP discovery performs bounded HEAD/HTML reads, scope-checks redirects and avoids binary GETs during inventory (`tests/test_web.py`); browser and host runtimes enforce declared capabilities and scope checks (`tests/test_recovery_and_runtime.py`); archive verification does not extract members and bounds expansion; SQLite immutable-record triggers, append-only events, content hashes, atomic promotion and crash recovery preserve lineage (`tests/test_application.py`, `tests/test_recovery_and_runtime.py`); the review panel validates loopback Host/Origin, one-use nonces and payload hashes (`tests/test_web.py`); typed MCP validation rejects unknown fields and exposes no approval tool (`tests/test_derivation_and_protocol.py`); and capture/export allowlists prevent unselected objects from entering Source Packs (`tests/test_application.py`).

## Deliberate non-changes

CDC does not silently remove broad filesystem scopes. The review panel now warns when a scope includes a home/root tree or private-network access, and the existing approval is still required. Hardlink exclusion may omit a legitimate shared-file collection, but tracking inode ownership across arbitrary source trees would be less predictable than an explicit boundary.

The optional browser runtime, host browser bridge authentication, mount-point changes, DNS/routing outside the process, and complete parser sandboxing were not redesigned. They require platform controls or would change the approved V1 runtime contract. No external service, account, API key or paid dependency was added.

The permanent adversarial suite is `tests/test_security_adversarial.py`. The complete deterministic suite remains the source of truth for ordinary functionality and conversational onboarding.
